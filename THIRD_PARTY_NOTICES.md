## OpenChamber — Fields of the Shire

`themes/shire.json` adapts the **Fields of the Shire** color palette from the
OpenChamber project, <https://github.com/openchamber/openchamber>, specifically:

- `packages/ui/src/lib/theme/themes/fields-of-the-shire-dark.json`
- `packages/ui/src/lib/theme/themes/fields-of-the-shire-light.json`

The colors were translated from OpenChamber's theme-token format into Zed's theme
schema (v0.2.0). The semantic mapping is derived from those files; the token names
and file structure are not. Deliberate changes: on the light side translucent
borders/selections were resolved to opaque tones, and doc-comment and gutter-number
colors were raised for contrast. No OpenChamber source code is included.

"Fields of the Shire" is the name of OpenChamber's theme and is used here only to
credit the origin of the palette. This project is not affiliated with or endorsed
by OpenChamber.
